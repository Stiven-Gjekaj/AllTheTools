# Getting help

## Understand the project

- [README.md](README.md) says what each tool does, and on which host.
- [docs/tools.md](docs/tools.md) says how each tool works on each host.
- [docs/roadmap.md](docs/roadmap.md) says what comes next.
- [AGENTS.md](AGENTS.md) sets the rules for anybody who changes this
  repository, human or agent.
- [TERMS.md](TERMS.md) says what the Software does to your data, and what you
  agree to when you run it.

## Ask a question or report a problem

- Search the existing
  [issues](https://github.com/Stiven-Gjekaj/AllTheTools/issues) first, in case
  somebody has already asked.
- If you found a bug, open a bug report.
- If you want a tool or an option, open a feature request.

When you report a problem, give the output of `att --version`, the command you
ran, and the operating system and its version.
A tool that works on one host and fails on another is the useful kind of
report, so name both.

Do not use the issue tracker for security problems.
See [SECURITY.md](SECURITY.md) for how to report those privately.
